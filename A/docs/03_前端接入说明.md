# 03 前端接入说明

## 一、“接入”

接入：
1. 前端按当前正式图谱结构展示知识图谱
2. 前端点击“确认修复”后，把结构化 JSON 发给后端
3. 后端再把 JSON 转成 Cypher 写入 Neo4j

## 二、前端需要接的内容

### 1. 图谱页展示
统一按下面 3 条主链路展示：
1. Symptom -> HAS_EQUIPMENT -> Equipment -> BELONGS_TO -> System
2. Symptom -> HAS_CAUSE -> Cause -> HAS_REPAIR -> Repair
3. Symptom -> HAS_CAUSE -> Cause -> HAS_DIAGNOSIS -> Diagnosis

### 2. “确认修复”按钮
前端点击后调用：
POST /graph/update

### 3. 故障树查询
前端查询某个症状的故障树路径：
GET /graph/fault-tree?symptom=排烟温度高

## 三、fetch 调用示例

```javascript
fetch("http://127.0.0.1:5001/graph/update", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify(graphJson)
})
.then(res => res.json())
.then(data => {
  console.log("更新结果:", data);
});
```
