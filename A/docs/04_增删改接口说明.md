# 04 增删改接口说明

## 一、节点接口

### 1. 新增节点
POST /graph/node/add

请求体：
{
  "label": "Cause",
  "name": "喷油器针阀卡滞"
}

### 2. 修改节点
POST /graph/node/update

请求体：
{
  "label": "Cause",
  "old_name": "喷油器卡滞",
  "new_name": "喷油器针阀卡滞"
}

### 3. 删除节点
POST /graph/node/delete

请求体：
{
  "label": "Cause",
  "name": "喷油器针阀卡滞"
}

## 二、关系接口

### 1. 新增关系
POST /graph/relation/add

请求体：
{
  "start_label": "Symptom",
  "start_name": "排烟温度高",
  "relationship": "HAS_CAUSE",
  "end_label": "Cause",
  "end_name": "喷油器针阀卡滞"
}

### 2. 删除关系
POST /graph/relation/delete

请求体：
{
  "start_label": "Symptom",
  "start_name": "排烟温度高",
  "relationship": "HAS_CAUSE",
  "end_label": "Cause",
  "end_name": "喷油器针阀卡滞"
}
